# Registry Provider

The Registry provider enables you to query the [Terraform Registry](https://registry.terraform.io) API to retrieve metadata about providers, modules, and policy libraries. This is a **read-only** provider - it queries registry data but does not manage any resources.

## Use Cases

- **Documentation Generation** - Pull resource schemas and docs into your own systems
- **Compliance Checking** - Verify which provider/module versions are available
- **Dependency Analysis** - Understand what resources a provider offers
- **Tooling Integration** - Build tools that need registry metadata
- **Version Pinning Automation** - Discover latest versions programmatically

## Example Usage

```terraform
terraform {
  required_providers {
    registry = {
      source = "thrashr888/registry"
    }
  }
}

provider "registry" {
  # Using default registry.terraform.io
}

# Get AWS provider details
data "registry_provider" "aws" {
  namespace = "hashicorp"
  name      = "aws"
}

output "aws_provider" {
  value = {
    id             = data.registry_provider.aws.id
    description    = data.registry_provider.aws.description
    tier           = data.registry_provider.aws.tier
    latest_version = data.registry_provider.aws.latest_version
    downloads      = data.registry_provider.aws.downloads
  }
}

# Get AWS provider versions
data "registry_provider_versions" "aws" {
  namespace = "hashicorp"
  name      = "aws"
}

output "aws_versions" {
  value = [for v in data.registry_provider_versions.aws.versions : v.version]
}

# Search for kubernetes providers
data "registry_search" "k8s" {
  query = "kubernetes"
  type  = "providers"
  tier  = "official"
}

output "k8s_providers" {
  value = [for r in data.registry_search.k8s.results : {
    name        = r.name
    namespace   = r.namespace
    description = r.description
  }]
}
```

## Private Registry Support

For private registries (like Terraform Cloud/Enterprise), configure the `host` and `token`:

```terraform
provider "registry" {
  host  = "app.terraform.io"
  token = var.tfc_token
}
```

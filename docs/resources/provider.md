# registry_provider (Resource)

Represents a Terraform provider from the registry. This is a read-only resource that can only be imported, not created or modified.

~> **Note:** This is a read-only resource for tracking registry metadata in Terraform state. It can be used with list blocks in Terraform 1.14+ for bulk import.

## Example Usage

```terraform
# Track the AWS provider in state
# This is a read-only resource - it fetches metadata from the registry
resource "registry_provider" "aws" {
  namespace = "hashicorp"
  name      = "aws"
}

output "aws_provider_info" {
  value = {
    description    = registry_provider.aws.description
    tier           = registry_provider.aws.tier
    latest_version = registry_provider.aws.latest_version
    downloads      = registry_provider.aws.downloads
  }
}
```

## Import

Import is supported using the following syntax:

```shell
# Import a provider using namespace/name format
terraform import registry_provider.aws hashicorp/aws
```

With Terraform 1.12 or later you can also import with an `import` block that uses the resource identity:

```terraform
import {
  to = registry_provider.aws
  identity = {
    name      = "aws"
    namespace = "hashicorp"
  }
}
```

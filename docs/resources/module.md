# registry_module (Resource)

Represents a Terraform module from the registry. This is a read-only resource that can only be imported, not created or modified.

~> **Note:** This is a read-only resource for tracking registry metadata in Terraform state. It can be used with list blocks in Terraform 1.14+ for bulk import.

## Example Usage

```terraform
# Track the VPC module in state
# This is a read-only resource - it fetches metadata from the registry
resource "registry_module" "vpc" {
  namespace       = "terraform-aws-modules"
  name            = "vpc"
  target_provider = "aws"
}

output "vpc_module_info" {
  value = {
    description = registry_module.vpc.description
    source      = registry_module.vpc.source
    verified    = registry_module.vpc.verified
    downloads   = registry_module.vpc.downloads
  }
}
```

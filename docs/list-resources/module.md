# registry_module (List Resource)

Lists or searches Terraform modules in the registry. Set `query` to search by text, `namespace` to list a namespace, or both.

~> **Note:** This list resource requires Terraform 1.14+ and is used with `terraform query` for bulk resource discovery. See the [Terraform Search guide](../guides/terraform-search) for the full workflow.

## Example Usage

```terraform
# List all modules from terraform-aws-modules
list "registry_module" "aws_modules" {
  provider = registry

  config {
    namespace = "terraform-aws-modules"
  }
}

# List only AWS modules from terraform-aws-modules
list "registry_module" "aws_modules_aws" {
  provider = registry

  config {
    namespace       = "terraform-aws-modules"
    target_provider = "aws"
  }
}

# Search modules by text
list "registry_module" "vpc" {
  provider = registry

  config {
    query           = "vpc"
    target_provider = "aws"
  }
}
```

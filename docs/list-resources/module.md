# registry_module (List Resource)

Lists Terraform modules from the registry by namespace.

~> **Note:** This list resource requires Terraform 1.14+ and is used with `terraform query` for bulk resource discovery.

## Example Usage

```terraform
# List all modules from terraform-aws-modules
list "registry_module" "aws_modules" {
  provider = registry

  config {
    namespace = "terraform-aws-modules"
  }
}

# List only AWS modules from terraform-aws-modules
list "registry_module" "aws_modules_aws" {
  provider = registry

  config {
    namespace       = "terraform-aws-modules"
    target_provider = "aws"
  }
}
```

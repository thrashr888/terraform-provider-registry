# registry_policy_library (List Resource)

Lists Terraform policy libraries from the registry by namespace.

~> **Note:** This list resource requires Terraform 1.14+ and is used with `terraform query` for bulk resource discovery.

## Example Usage

```terraform
# List all HashiCorp policy libraries
list "registry_policy_library" "hashicorp" {
  provider = registry

  config {
    namespace = "hashicorp"
  }
}
```

# registry_provider (List Resource)

Lists or searches Terraform providers in the registry. Set `query` to search by text, `namespace` to list a namespace, or both.

~> **Note:** This list resource requires Terraform 1.14+ and is used with `terraform query` for bulk resource discovery. See the [Terraform Search guide](../guides/terraform-search) for the full workflow.

## Example Usage

```terraform
# List all HashiCorp providers
list "registry_provider" "hashicorp" {
  provider = registry

  config {
    namespace = "hashicorp"
  }
}

# List only official HashiCorp providers
list "registry_provider" "hashicorp_official" {
  provider = registry

  config {
    namespace = "hashicorp"
    tier      = "official"
  }
}

# Search providers by text
list "registry_provider" "kubernetes" {
  provider = registry

  config {
    query = "kubernetes"
  }
}
```

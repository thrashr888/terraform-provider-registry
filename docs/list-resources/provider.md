# registry_provider (List Resource)

Lists Terraform providers from the registry by namespace.

~> **Note:** This list resource requires Terraform 1.14+ and is used with `terraform query` for bulk resource discovery.

## Example Usage

```terraform
# List all HashiCorp providers
list "registry_provider" "hashicorp" {
  provider = registry

  config {
    namespace = "hashicorp"
  }
}

# List only official HashiCorp providers
list "registry_provider" "hashicorp_official" {
  provider = registry

  config {
    namespace = "hashicorp"
    tier      = "official"
  }
}
```
